# Práctica de Jest

Pruebas unitarias para funciones de arreglos, texto y divisibilidad.

## Tecnologías

- JavaScript
- Jest

## Instalación y ejecución

```bash
npm install --save-dev jest && npm test
```

> La dependencia Jest del package.json actual usa el marcador inválido `...`; `npm install --save-dev jest` lo reemplaza por una versión válida.

## Uso

Ejecuta `tests/functions.test.js`.
